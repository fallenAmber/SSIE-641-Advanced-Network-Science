# M02 : Small-World Networks

This module explores why large social networks can remain highly clustered while still having very short path lengths.

## Topics
- Milgram's six degrees of separation
- Shortest-path distance
- Average path length
- Network diameter
- Local clustering coefficient
- Average clustering
- Global clustering / transitivity
- Watts–Strogatz small-world model
- Rewiring probability and long-range shortcuts

## Key Insight
A regular ring has high clustering but long paths, while a random network has short paths but low clustering.

The Watts–Strogatz model shows that rewiring only a small fraction of links can dramatically reduce average path length while preserving most of the network's clustering.
