# SSIE 641 — Advanced Topics in Network Science

Coursework, computational experiments, and selected mini-projects from
**SSIE 641: Advanced Topics in Network Science** at School of Systems Science and Industrial Engineering, Binghamton University.

Instructor: Dr. Sadamori Kojaku  
Semester: Fall 2026

## Topics

- Euler tours and graph representation
- Small-world networks
- Network robustness
- Friendship paradox and degree distributions
- Community detection and clustering
- Network centrality
- Random walks
- Network embeddings
- Graph neural networks

## Repository Structure

### M01 — Euler Tour
Graph representation, Euler paths/circuits, and the Binghamton bridge mini-project.

### M02 — Small World
Shortest-path distance, diameter, clustering coefficients,
Watts–Strogatz networks, and small-world behavior.

### M03 — Robustness
Network resilience under random and targeted node removal.

### M04 — Friendship Paradox
Degree distributions, heavy tails, and sampling bias in networks.

### M05 — Clustering
Community structure and community detection.

### M06 — Centrality
Different notions of node importance.

### M07 — Random Walks
Random walks and diffusion on networks.

### M08 — Network Embedding
Representing network structure in geometric spaces.

### M09 — Graph Neural Networks
Message passing and graph-based machine learning.
